# Contributing

Thanks for your interest in improving this prototype. Please follow these steps so contributions are consistent and easy to review.

## Code of conduct

Be respectful and constructive. Report issues and PRs in a helpful, reproducible way.

## How to contribute

1. Fork the repository and create a feature branch: `git checkout -b feat/your-feature`.
2. Run the smoke test locally: `python simulate_lambda.py` (see README for details).
3. Add tests for new functionality where appropriate.
4. Open a pull request with a clear description and a short changelog.

## Issues

- Use the issue templates (bug/feature) and include steps to reproduce, expected behavior, and environment.

## Style

- Python: follow PEP8. Keep functions small and documented.
- Add docstrings for public functions and modules.

## CI and tests

- The repository includes a lightweight CI smoke test. Ensure your changes pass the smoke test before opening a PR.
